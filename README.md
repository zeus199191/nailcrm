# CRM мастера маникюра — Алена Макарова, Канск

Сайт с онлайн-записью и CRM для мастера, который работает один: делает маникюр и обучает мастеров.
Работает на вашем сервере, без абонентской платы и внешних зависимостей: Node.js 22 и встроенная SQLite.
Сделано по образцу CRM «Бумсистем», но без кассы, терминала, банка, склада, сотрудников и зарплат.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Сайт** | Главная страница сервера. Прайс, курсы, портфолио и отзывы подтягиваются из CRM. **Онлайн-запись**: клиентка выбирает услуги, видит только свободные окна по графику и записывается. Заявка на услугу или курс. Кнопка «Вход» ведёт в CRM (`/crm`) |
| **Главная** | Записи на сегодня, получено за день и за месяц, налог к уплате, чеки без отметки, онлайн-записи и заявки, дни рождения на неделе, потоки обучения и долги учениц |
| **Календарь** | День и неделя по часам, на телефоне — лента дней. Записи клиенток, занятия обучения и личное время. Услуги из прайса, длительность и сумма считаются сами, учитывается постоянная скидка, предупреждение о пересечении. «Пришла · оплата», «Не пришла», доплата |
| **Клиентки** | Поиск, фильтры (постоянные, давно не были, новые, ученицы, именинницы). Карточка: история визитов, сколько оплачено, средний чек, как часто приходит, заметки (форма, длина, аллергии), звонок, WhatsApp, SMS. Импорт списка из Excel или заметок |
| **Заявки** | Онлайн-записи с сайта (подтвердить, перенести, отклонить) и заявки на услуги и курсы. Заявка превращается в запись или в ученицу в одно нажатие |
| **Обучение** | Курсы (видны на сайте), потоки с датами и местами, занятия в календаре, ученицы с оплатой частями, печать сертификата с номером |
| **Финансы самозанятой** | Доходы (услуги, обучение), расходы по категориям, прибыль. Налог НПД: 4% с физлиц, 6% с ИП и компаний, срок уплаты — до 28 числа. Отметка «чек в Мой налог выдан» и список оплат без чека. Годовой лимит 2,4 млн |
| **Маркетинг** | **Аналитика**: доход за 12 месяцев, средний чек, загрузка, возвращаемость, источники, что приносит деньги. **SMM**: контент-план на месяц, пост с фото одной кнопкой в MAX, Telegram, ВКонтакте и «Образцы работ» на сайте, публикация по расписанию. **SMS-рассылки** по сегментам и автосообщения. **Портфолио**, **отзывы** для сайта, **ИИ-помощник** |
| **SMS** | С личного Android-телефона (приложение SMS Gateway for Android, по тарифу оператора) или через SMS.ru. Очередь с паузой, дневным лимитом и тихими часами. Автоматически: напоминание накануне, подтверждение записи, просьба об отзыве, «пора на коррекцию» через N дней, поздравление с днём рождения. Отметка «не отправлять SMS» у клиентки |
| **ИИ** | GigaChat (Сбер) или YandexGPT: посты о работе, «улучшить» и «короче», ответы клиенткам, акции, описание курса, текст SMS, идеи постов на месяц сразу в контент-план. ИИ не придумывает цены и акции |
| **Уведомления** | Бот в Telegram и/или MAX присылает мастеру новые онлайн-записи и заявки, а вечером — план на завтра. Команды боту: «сегодня», «завтра» |
| **Телефон** | Адаптивный интерфейс, нижняя панель вкладок; на iPhone ставится как приложение («Поделиться → На экран „Домой“»), вход сохраняется 90 дней |

## Демо без сервера

`dist/demo.html` — сайт и CRM в одном файле с примером данных. Данные хранятся только в браузере.
Вход: логин `admin`, пароль `demo`. Собрать заново: `node tools/build-demo.js`.

## Установка на сервер (Ubuntu 22/24)

```
scp nailcrm.tar.gz root@IP-СЕРВЕРА:/root/
ssh root@IP-СЕРВЕРА
tar xzf nailcrm.tar.gz && cd nailcrm
bash install.sh nails.ваш-домен.ru  ваша@почта.ru
```

Сначала создайте A-запись домена на IP сервера. Без домена (`bash install.sh`) сайт откроется на `http://IP:8081`.
Скрипт покажет пароль первого входа (логин `admin`).

**Можно на тот же сервер, что и Бумсистем**: у CRM своя служба `nailcrm`, порт 3100, база `/var/lib/nailcrm`
и отдельный домен в nginx. Бумсистем это не затрагивает.

Часовой пояс по умолчанию — Красноярск (Канск). Другой: `TZ_NAME=Asia/Irkutsk bash install.sh ...`

## Первые шаги

1. **Настройки → Профиль**: телефон, адрес, ссылки на соцсети и отзывы, фото для сайта.
2. **Настройки → График**: рабочие дни и часы, онлайн-запись, выходные и отпуск.
3. **Услуги и цены**: проверьте цены и длительность — по длительности считаются свободные окна.
4. **Маркетинг → Портфолио**: загрузите лучшие работы.
5. **Настройки → Уведомления**: бот Telegram или MAX → «Получить код привязки» → отправьте код боту.
6. **Настройки → SMS** и **ИИ-помощник** — по желанию.

## Обновление и домен — из CRM

**Настройки → Обновление CRM.** Кнопка «Обновить» появляется, когда в репозитории GitHub (по умолчанию `zeus199191/nailcrm`, ветка `main`) лежит версия новее установленной (поле `version` в package.json). CRM сохраняет копию базы и кода, ставит новую версию через install.sh и, если она не запустилась, сама возвращает прежнюю. Запасной вариант без GitHub: «Загрузить архив nailcrm.tar.gz».

**Настройки → Домен сайта.** Добавьте у регистратора A-запись на IP сервера, введите домен и нажмите «Подключить»: nginx и бесплатный HTTPS-сертификат настраиваются автоматически. Адрес `http://IP:8081` остаётся запасным входом.

Журнал обеих операций — `/var/lib/nailcrm/update.log`, служба — `nailcrm-update` (запускается от root по заявке из CRM).

## Обслуживание

| Задача | Команда |
|---|---|
| Статус / логи | `systemctl status nailcrm` / `journalctl -u nailcrm -n 100` |
| Обновление | распаковать новый архив и снова `bash install.sh` |
| Сброс пароля | `cd /opt/nailcrm && sudo -u nailcrm CRM_DATA=/var/lib/nailcrm node scripts/reset-password.js admin НовыйПароль` |
| Копия базы | автоматически в 03:30 в `/var/lib/nailcrm/backups/` (30 штук); вручную — Настройки → «Скачать копию базы» |

## Структура

```

lib/db.js          база и начальные данные (прайс, курсы)
lib/api.js         API CRM, онлайн-запись, заявки
lib/shared.js      общие расчёты (свободные окна, шаблоны SMS) — сервер и браузер
lib/landing.js     сайт мастера
lib/sms.js         SMS-очередь и автосообщения
lib/social.js      Telegram, MAX, ВКонтакте: уведомления и публикации
lib/ai.js          GigaChat / YandexGPT
public/js/*.js     интерфейс CRM
tools/             сборка демо-версии
```
